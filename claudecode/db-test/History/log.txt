QUERY PATH EXAMPLES:
====================
1. Get all orders for a user:
   SELECT * FROM orders o JOIN users u ON o.user_id = u.user_id WHERE u.email = ?

2. Get all products in an order:
   SELECT p.* FROM products p
   JOIN order_items oi ON p.product_id = oi.product_id
   WHERE oi.order_id = ?

3. Get order summary with user info:
   SELECT u.first_name, o.order_date, o.total_amount
   FROM orders o JOIN users u ON o.user_id = u.user_id

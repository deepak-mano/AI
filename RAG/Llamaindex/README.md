model   =>  This program performs the below.

1) Scrap a NVIDIA website on different Models and specs
2) Chunks into nodes, vectorize and store in in-memory DB
3) Retreives the Model details based on the prompt
4) Retreives based on either query search or a step by step search
5) For a step by step approach, displays the retrieved nodes and score.
6) Provides a final response from llm.
